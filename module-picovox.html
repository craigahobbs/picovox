(static) speak(text, optionsopt) → {module:picovox~Playback}

Speak text aloud in a browser, with Web Audio - playback starts with the first sentence's first blocks, while the rest are synthesized (a few seconds ahead of playback). Synthesis runs on the main thread, a block at a time between the page's other work - for long texts, use stream in a Web Worker and play its blocks.

Call it from a user gesture (a click), so the browser allows the audio to start.

(static) stream(text, optionsopt) → {AsyncIterable.<Float32Array>}

Synthesize speech as a stream of sample blocks, made as they're taken - the text a sentence at a time, each sentence a fraction of a second at a time, so the first audio comes quickly. Each sentence starts with a short pause (0.24 seconds, 0.4 before a paragraph - the text's first sentence starts one). The blocks, concatenated, are synthesize's samples.

Synthesis runs on the calling thread while each block is taken - in a browser, take the blocks in a Web Worker to keep the page responsive.
