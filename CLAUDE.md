# CLAUDE.md

Notes for coding agents working in this repository.

## Project overview

voice-synth is a from-scratch speech synthesizer in JavaScript - a small neural network that speaks interpretable
source-filter synthesizer parameters, rendered by a JavaScript synthesizer (no recorded speech, no runtime
dependencies) - and a public-domain audiobook player web app built on it. (The first, rule-based formant synthesizer
and its tools were removed in commit 33fbfad - see git history.)

- `lib/` - the pure (DOM-free) library code: the text front end (`lexicon.js` - normalization and phrasing; `g2p.js` -
  the grapheme-to-phoneme network's inference; `phonemes.js`), WAV encoding (`wav.js`), and book-text preparation
  (`catalog.js`, `gutenberg.js`, `epub.js`, `zip.js`). Runs in Node and browsers. 100% test coverage.
  `lib/models/` holds the generated model modules (`g2pModel.js`, `voiceModel.js`) that `make train` reproduces.
- `nn/js/` - the voice model's runtime (browser and Node): `model.js` (the network), `render.js` (the synthesizer),
  `package.js` (the generated module's loader), `params.js` (generated by `nn/params.py`), `tokens.js`, `transforms.js`,
  `voices.js` (the designed voices, `data/nn/voices.json`), `lf.js`, `rng.js`, `fft.js`; Node tools `speak.js` (text to
  WAV), `voicescheck.js`, `packagecheck.js`, `tokenizeLines.js`.
- `nn/` - the Python training pipeline (`build/venv-nn`): the front end's port (`frontend.py`, `g2pmodel.py`), the G2P and
  heteronym models (`g2p.py`, `heteronyms.py`, `context.py`, `contextlabels.py`, `readings.py`), the data (`data.py`,
  `align.py`, `multi.py`, `cremad.py`, `accent.py`), the differentiable synthesizer (`params.py`, `dsynth.py`, `lf.py`,
  `rng.py`, `spectral.py`), the model and its training (`model.py`, `trainmulti.py`, `losses.py`, `discriminator.py`,
  `quant.py`), distillation (`distill.py`), export (`export.py`, `package.py`, `synthesize.py`, `parity.py`), the
  listener panel's scoring (`panel.py`), and the pipeline's tools (`gpulock.py`, `smoke.py`, `stepcheck.py`).
  `nn/__init__.py` documents each module.
- `static/audiobook/` - the audiobook player app (static files, ES modules, no build step): the interface (`app.js`),
  playback (`engine.js`), the synthesis worker (`worker.js`), listener state (`store.js`), the downloaded-book cache
  (`bookcache.js`), and the book sources (`sources/`). The root `index.html` shows `README.md` (MarkdownUp).
- `tools/` - the training dashboard (`dashboard/`), the corpus download (`corpora.py`), the listener models
  (`listeners.py`, `build/venv-listeners`), the catalog build (`catalog.js`), the source checks
  (`gutenbergcheck.mjs`, `standardebookscheck.mjs`), `browsercheck.js`, `heteronyms.js`, `serve.js`, `devlog.js`,
  make train's bookkeeping (`trainstage.sh`, `trainutil.sh` - the stage events and logs, the utilization samples), and
  the panel's texts (`panel-texts.json`).
- `test/` - unit tests (`node:test`), one `test<Module>.js` per `lib/` module.
- `data/` - the catalog, the CMU Pronouncing Dictionary (G2P training), `data/nn/` (the recipe `train.json`, the
  speaker pool, the G2P and heteronym data, the designed voices, the single-speaker exports `slt`/`bdl`), and
  `data/targets/` (the four labeled ARCTIC speakers' analysis settings).

## javascript-build

This is a [javascript-build](https://github.com/craigahobbs/javascript-build#readme) package. Read the javascript-build
skill before running tests, lint, coverage, or changing the Makefile:
[`../javascript-build/SKILL.md`](../javascript-build/SKILL.md) if that file exists, otherwise
[https://raw.githubusercontent.com/craigahobbs/javascript-build/main/SKILL.md](https://raw.githubusercontent.com/craigahobbs/javascript-build/main/SKILL.md).

Local Makefile overrides:

- `ESLINT_ARGS` - also `static/audiobook/` and `tools/` (not the generated `lib/models/`)
- `GHPAGES_SRC` - `build/site/` (the published app and catalog)

`make commit` (test, lint, doc, cover) is the gate before committing. `make train` rebuilds the generated models from
the recipe (`data/nn/train.json`); `build/venv-nn/bin/python -B -m nn.smoke` runs every training entry point for a few
steps on the CPU.

## Conventions

- Code style: 4-space indent, single-quoted strings, single-quoted object keys, a short comment above each function and
  block, descriptive names (no one-letter names - `id-length`), lines at most 140 characters.
- Voice changes are judged by measurement, not by ear: the listener panel (`nn/panel.py` - UTMOS, Whisper's WER,
  speaker similarity; `nn.distill eval`) over the panel texts; compare averages over several seeds.
- Refactors must leave the app's audio bit-identical - compare a hash of the worker's audio
  (`static/audiobook/worker.js` `streamNeuralUnit` over `tools/panel-texts.json`, both voices) before and after - and
  the trainer exact (`nn/stepcheck.py` before and after). The generated models must still reproduce byte for byte from
  their checkpoints (`nn.export` + `nn.package`; `nn.context export` for the G2P).
- The browser app must keep working from plain static hosting (`python3 -m http.server` and GitHub Pages) - book texts
  are fetched from their sources with CORS, never through a proxy.
